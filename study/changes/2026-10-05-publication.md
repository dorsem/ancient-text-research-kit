# Первый публичный выпуск

Версия 0.1.0 публикует рабочую исследовательскую редакцию 005, инструкции агентам и воспроизводимую сборку. Пользовательское условие успеха: читатель открывает исследование по публичной ссылке, может создать собственный экземпляр шаблона и увидеть историю последующих пересмотров.

Содержательные выводы C01–C06 и 42 адресованные строки O.1920 сохранены. Публикация не повышает их уверенность и не меняет draft на checked. Добавлены условия повторного использования собственных материалов: MIT для кода и инструкции, CC BY 4.0 для исследования.

Основной синтез переносится в репозиторий. После проверенного изменения основной ветки GitHub Actions пересобирает читательский сайт. Проверки охватывают структуру, ссылки, защиту ручных изменений и сохранение обозначений в чтениях; истинность гипотез остаётся отдельной предметной задачей.
