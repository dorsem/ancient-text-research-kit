Что применимо к лаборатории в 2026 году

Проверено 5 октября 2026 по официальным описаниям. Это подбор подходящих возможностей, а не рейтинг распространённости инструментов.

ПодходЧто он даётРешение для нашей лаборатории
EpiDoc и TEIИздание древних документов, связь транскрипции с носителем и участками изображенияСразу сохранять предмет, поверхность, строку и редакционные различия; XML-экспорт добавлять при реальной потребности обмена
AGENTS.mdПереносимый файл инструкций агенту в проектеИспользовать сейчас, сохранять возможность последовательного выполнения ролей
LangGraphДлительные процессы с состоянием, предсказуемые и модельные шагиОтложить до появления устойчивого сценария автоматических запусков
OpenAI Agents SDKИнструменты, передача задач, сессии и трассировка работы агентовВозможный исполнитель; исследовательские записи должны оставаться переносимыми
RO-CrateУпаковка исследовательских файлов с машиночитаемыми метаданнымиОриентир будущего экспорта; текущий JSON не объявляется совместимым RO-Crate
GitHub и CITATION.cffИстория изменений, обсуждение исправлений, сведения для цитированияИспользуются репозиторий dorsem/ancient-text-research-kit и сайт GitHub Pages; условия MIT и CC BY 4.0 выбраны владельцем

EpiDoc 9.8 опубликован 18 марта 2026. TEI, раздел Primary Sources описывает поверхности и зоны факсимиле и связь с транскрипцией. Эти правила полезнее для древних текстов, чем увеличение числа агентов само по себе.

AGENTS.md задаёт открытый формат инструкций. LangGraph поддерживает состояние, возобновление и участие человека. OpenAI Agents SDK предлагает средства выполнения и наблюдения за агентами. Их наличие не подтверждает точность дешифровки; выбор исполнителя отдельно проверяется на наших примерах.

RO-Crate 1.2, введение объясняет пакет файлов и метаданных. Документация CITATION.cff описывает показ сведений для цитирования на GitHub. Сведения о возможностях взяты из документации; решения в третьей колонке являются нашей рекомендацией.

Рабочая редакция. Источники и разночтения проверяются отдельно от программных проверок. HTML собран из Markdown.
