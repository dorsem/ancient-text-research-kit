# Где редактировать исследование

Основная рабочая запись теперь находится в репозитории dorsem/ancient-text-research-kit: study/reports/main_research.md. Именно этот файл продолжает пополняемое исследование. Локальная копия репозитория используется для работы, GitHub хранит опубликованную историю. Старая лабораторная папка сохраняет исходный архив и ранее подготовленный Word; её синтез не обновляется отдельно от репозитория.

Владелец разрешил обновлять этот репозиторий по мере изменения исследования. Каждое обновление должно пройти сверку источников, сохранение вариантов и программные проверки. Разрешение относится к продолжению этого проекта; новые площадки, сторонние личные материалы, дополнительные расходы и изменение лицензий требуют отдельного решения.

Для каждого нового материала заполняется карточка, затем уточняются evidence и claims в реестре. Формулировка вывода хранится в основном тексте, реестр хранит связи и состояние. В study/changes добавляется причина пересмотра. Выполняются python3 tools/lab.py build, python3 tools/lab.py validate и тесты. Затем создаётся коммит; обычные изменения можно отправить в основную ветку. При совместной работе используйте ветку dorsem/смысл-изменения и pull request.

Каждый законченный и проверенный исследовательский цикл отправляется на GitHub в рамках уже выданного разрешения; публикация входит в завершение работы. После отправки проверить успешную сборку Pages и появление изменённого текста на сайте.

На GitHub проверки повторяются. После успешного push в dorsem/main сайт обновляется автоматически. Пока изменений исследования нет, новый коммит и публикация не требуются. Это связь сайта с изменениями репозитория, а не фоновый поиск новой литературы.

HTML является производным. Сборка откажется затирать вручную изменённый HTML; сначала перенесите нужную правку в Markdown и сохраните копию, затем пересоберите site. Word также является экспортом; его ручные правки сначала сопоставляются с основной записью. Двусторонняя автоматическая синхронизация Word не выполняется.

Предел 30 страниц проверяется по актуальному рендеру основного документа, вместе с изображениями и библиографией. Число 10 относится к проверенной исходной Word-редакции 005. HTML не имеет фиксированного числа страниц. Перед новым пагинированным выпуском сохраняются хеш исходника, хеш экспорта, средство рендера и измеренное число страниц. Старое измерение не переносится на изменённый документ.
