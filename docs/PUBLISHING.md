# Публикация и обновление сайта

Площадка проекта: [dorsem/ancient-text-research-kit](https://github.com/dorsem/ancient-text-research-kit). Читательская версия: [GitHub Pages](https://dorsem.github.io/ancient-text-research-kit/). Владелец разрешил публикацию и последующие обновления по мере изменения исследования 5 октября 2026; в тот же день выбраны MIT и CC BY 4.0 для соответствующих собственных материалов.

Репозиторий является шаблоном. Другой исследователь может выбрать Use this template, задать новый вопрос и пользоваться тем же протоколом. Ссылки на исходный проект и сведения об авторе в своём экземпляре следует обновить, сохранив необходимую атрибуцию. Pages в новом экземпляре нужно включить в Settings → Pages → GitHub Actions.

Основная ветка: dorsem/main. На pull request и push выполняются проверки на Python 3.9 и 3.12. Сборка проверяет свежесть HTML; изменённые вручную страницы нельзя молча затереть. Новая версия сайта развёртывается только после успешных проверок основной ветки. Workflow не редактирует выводы и не выполняет внешний поиск.

Для обычного исследовательского обновления: обновить карточки, основной текст и реестр; записать причину пересмотра в study/changes; выполнить build, validate и тесты; проверить diff и опубликовать коммит. HTML и исходный текст должны относиться к одной редакции. При отказе проверки сайт сохраняет последнюю успешно опубликованную версию.

Внешние фото и PDF представлены ссылками. [Условия нашего пакета](../LICENSING.md) не меняют права на современные издания, чужие переводы и музейные фотографии. Первичные источники и рабочие гипотезы не получают научного одобрения от одного факта публикации.
