# Что применимо к лаборатории в 2026 году

Проверено 5 октября 2026 по официальным описаниям. Это подбор подходящих возможностей, а не рейтинг распространённости инструментов.

| Подход | Что он даёт | Решение для нашей лаборатории |
|---|---|---|
| EpiDoc и TEI | Издание древних документов, связь транскрипции с носителем и участками изображения | Сразу сохранять предмет, поверхность, строку и редакционные различия; XML-экспорт добавлять при реальной потребности обмена |
| AGENTS.md | Переносимый файл инструкций агенту в проекте | Использовать сейчас, сохранять возможность последовательного выполнения ролей |
| LangGraph | Длительные процессы с состоянием, предсказуемые и модельные шаги | Отложить до появления устойчивого сценария автоматических запусков |
| OpenAI Agents SDK | Инструменты, передача задач, сессии и трассировка работы агентов | Возможный исполнитель; исследовательские записи должны оставаться переносимыми |
| RO-Crate | Упаковка исследовательских файлов с машиночитаемыми метаданными | Ориентир будущего экспорта; текущий JSON не объявляется совместимым RO-Crate |
| GitHub и CITATION.cff | История изменений, обсуждение исправлений, сведения для цитирования | Используются репозиторий dorsem/ancient-text-research-kit и сайт GitHub Pages; условия MIT и CC BY 4.0 выбраны владельцем |

[EpiDoc 9.8](https://epidoc.stoa.org/gl/latest/) опубликован 18 марта 2026. [TEI, раздел Primary Sources](https://tei-c.org/release/doc/tei-p5-doc/en/html/PH.html) описывает поверхности и зоны факсимиле и связь с транскрипцией. Эти правила полезнее для древних текстов, чем увеличение числа агентов само по себе.

[AGENTS.md](https://agents.md/) задаёт открытый формат инструкций. [LangGraph](https://docs.langchain.com/oss/python/langgraph/overview) поддерживает состояние, возобновление и участие человека. [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) предлагает средства выполнения и наблюдения за агентами. Их наличие не подтверждает точность дешифровки; выбор исполнителя отдельно проверяется на наших примерах.

[RO-Crate 1.2, введение](https://www.researchobject.org/ro-crate/specification/1.2/introduction.html) объясняет пакет файлов и метаданных. [Документация CITATION.cff](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files) описывает показ сведений для цитирования на GitHub. Сведения о возможностях взяты из документации; решения в третьей колонке являются нашей рекомендацией.
